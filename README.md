# Q8 Petrol (Lanka) — Premium Static Website

## Structure

- `index.html`
- `css/styles.css`
- `js/main.js`
- `assets/favicon.svg`

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Notes

- No framework or build process is required.
- The layout is mobile-first and responsive.
- Animations respect `prefers-reduced-motion`.
- The hero uses CSS-generated orbital trade graphics, so it does not depend on stock imagery.
- Replace `trade@q8petrol.com` with the client's confirmed trade/contact email before production.
- Telephone links use the numbers supplied in the brief.
